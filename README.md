## About the Project

This repository contains my personal portfolio website, created to present my experience, technical interests, and selected work in an accessible and engaging way.

Built with **HTML5, CSS3, and vanilla JavaScript**, the website prioritizes fast loading, maintainable code, and a smooth experience across devices—without relying on a frontend framework or build pipeline.

## Features

- **Responsive layout** — optimized for desktop, tablet, and mobile screens.
- **Multilingual experience** — English, Turkish, and Arabic, with right-to-left support.
- **Light and dark themes** — consistent styling with a theme switcher.
- **Interactive details** — subtle animations, decorative visual effects, and section-aware navigation.
- **Accessibility-conscious motion** — respects reduced-motion preferences.
- **Project showcase** — a dedicated presentation of selected work and technical experience.
- **Professional profile** — information about my background, skills, résumé, and ways to connect.
- **Lightweight architecture** — a static website with no required framework or external runtime.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/M-Nour-44/portfolio.git
cd portfolio
```

Open `index.html` using a local development server. For example, use the **Live Server** extension in Visual Studio Code, or start a server with Python:

```bash
python -m http.server 5500
```

Then visit **http://localhost:5500**.

No `npm install` or build step is required to view the portfolio.

## Deployment

This is a static website and can be hosted with **GitHub Pages** or any other static hosting service.

To publish using GitHub Pages:

1. Open **Settings → Pages** in the GitHub repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` directory.
4. Save the settings and access the site using the URL provided by GitHub Pages.

Keep the relative paths between HTML, CSS, JavaScript, and asset files intact when deploying.
